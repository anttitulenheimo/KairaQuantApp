WHAT THIS TESTS

A simple rule.
Transparent accounting.

The initial crypto purchase uses 10% of capital including fees. The weight then returns to 10% on the first day of each month at 00:00 UTC. Fees apply only to the amount traded.

BTC, ETH and both cost levels use separate simulated portfolios. At period end, return and drawdown include a liquidation fee reserve. This reserve is not a sale; portfolio value shows holdings before the reserve.

This is a software test environment, not a historical performance study. V8 and V10 forward validation remain separate. The simulation uses no market data, API keys or trading orders.
