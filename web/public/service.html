The server executes.
The browser reports.

Python uses the same synthetic monthly rule and broker scenarios as V14. Decisions are persisted in SQLite before their effects. Retrying an HTTP command with the same request ID does not repeat its effects.

Run on server starts the test year in Python. You can close the browser. Restarting the service resumes an active run; a paused run stays paused. The failure profile deliberately pauses after a lost acknowledgement and resumes with the same order ID.

If the connection drops, values are marked stale and controls are disabled. The interface never replaces server balances with a browser simulation. Press Ctrl+C in the terminal to stop the service; shutting down the computer also stops it.

The broker and prices are simulated. The service listens only on your computer. GitHub Pages stores no database, access token or broker credentials. V8/V10 studies and the legacy ML paper application remain separate.
